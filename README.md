
# Netflix Global Market Performance Analysis

## Project Overview
Analysis of Netflix content distribution across countries to identify major content markets.

## Objectives
- Country-wise content distribution
- Top 10 country ranking
- Country contribution comparison
- Movies vs TV Shows comparison
- Business recommendations

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Visualizations
- Top 10 Countries Bar Chart
- Country Content Comparison Chart

## Outputs
- Netflix_Country_Analysis.csv
- Netflix_Country_Content_Comparison.csv
